# Trabalho Final – Programação para Automação de Testes

Este repositório contém a implementação do trabalho final individual da disciplina **Programação para Automação de Testes**, conforme as instruções fornecidas em aula.

## Descrição

O objetivo do projeto é **criar scripts que façam os testes previamente definidos passarem**, sem alterar o arquivo de testes original.

Todos os scripts de lógica estão implementados no arquivo:

```
projeto_final/trabalho.js
```

O script de testes está localizado em:

```
projeto_final/testes/trabalho-final.js
```
